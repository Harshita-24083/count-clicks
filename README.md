Counter App 🔢

A simple and interactive Counter App built using HTML, CSS, and JavaScript.

Features

- Increase the count using the plus (+) button.
- Decrease the count using the minus (-) button.
- Reset the count to its initial value.
- Simple and user-friendly interface.

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Open the project in your browser.
2. Click the + button to increase the count.
3. Click the - button to decrease the count.
4. Click Reset to reset the count.
